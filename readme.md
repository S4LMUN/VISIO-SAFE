# VISIO-SAFE

### ระบบช่วยเหลือการมองเห็นด้วย AI แบบออฟไลน์

> **เปลี่ยนสิ่งที่กล้องมองเห็น ให้กลายเป็นสิ่งที่ผู้ใช้รับรู้ได้**

VISIO-SAFE คือแนวคิดระบบช่วยเหลือผู้พิการทางสายตาที่ใช้ **AI, Computer Vision และ Distance Sensing** เพื่อช่วยตรวจจับสิ่งกีดขวาง วิเคราะห์ความเสี่ยง และแจ้งเตือนผ่านเสียงและแรงสั่นสะเทือน

ออกแบบภายใต้แนวคิด **Offline-First** โดยมุ่งให้การประมวลผลหลักเกิดขึ้นภายในอุปกรณ์

**สถานะ:** `อยู่ระหว่างการวิจัยและออกแบบระบบ`

## เทคโนโลยี

| ส่วน        | เทคโนโลยีที่วางแผนใช้                     |
| ----------- | ----------------------------------------- |
| AI / Vision | Python · OpenCV · YOLO                    |
| System Core | C++                                       |
| Hardware    | Embedded Board · Camera · Distance Sensor |
| Output      | Speaker · Vibration Motor                 |
| Development | Linux · Windows · Neovim · VS Code · Git  |

> **Python รับผิดชอบการรับรู้และวิเคราะห์ภาพ ส่วน C++ รับผิดชอบการควบคุมระบบ**

**แพลตฟอร์ม Hardware:** `อยู่ระหว่างการพิจารณา`

ตัวเลือกที่กำลังพิจารณา ได้แก่ **Arduino, Raspberry Pi หรือ Embedded Platform อื่นที่เหมาะสม**
